# Sports Equipment Rental Tracker

A menu-driven Python application to manage sports equipment,
rental transactions, returns, and rental charges.

## Features

- Add and view sports equipment
- Search equipment by name
- Track available quantity
- Rent equipment to customers
- Return rented equipment
- Calculate rental charges
- Track due dates
- View overdue rentals
- Generate rental reports
- Store records in JSON files

## Technologies Used

- Python
- JSON
- File Handling
- Functions
- Lists and Dictionaries
- DateTime

## Installation

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Open the project folder:

```bash
cd Sports_Equipment_Rental_Tracker
```

Run the application:

```bash
python main.py
```
